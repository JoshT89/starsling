# STARSLING — Cosmic Odyssey

A tactile, one-thumb cosmic slingshot roguelite built for mobile touchscreens and desktop browsers.

## Features
- **One-Thumb Bullet-Time Slingshot**: Touch & pull anywhere on screen to slow time, preview curved ricochets, and launch skyward.
- **Infinite Chain Reactions**: Every Star-Prism, Bumper Moon, Supernova Core, or Void Drifter you smash **refunds a mid-air Sling Charge** and climbs a harmonic C-Lydian synth scale.
- **Aurora Bank-Shots & Supernova Fever**: Ricochet off shimmering side walls for **2x Bank-Shot trick bonuses**, and hit a 12x air streak to unleash **Invincible Rainbow Fever Overdrive**.
- **4 Game Modes**:
  - **Odyssey**: Climb 6 cross-fading celestial biomes, draft stackable **Starlight Relics** at Celestial Shrines, and battle multi-phase **Constellation Titans**.
  - **Daily Cosmos**: Deterministic daily seeded challenge (`YYYY-MM-DD`) with 1.5x Stardust bonus.
  - **Blitz 60s**: High-octane 60-second score attack where Fever triggers add `+2.5s` bonus time.
  - **Zen Sky**: Chill, hazard-free endless musical flow.
- **Meta-Progression**: 6 unlockable **Star-Spirits** (*Luma, Nyx, Sol, Echo-9, Cosmo, Astra*), **Starlight Workshop** upgrades, rotating **Cosmic Quests**, and **Trophies**.
- **Zero External Assets Needed**: Custom HiDPI 2D Canvas engine + procedural Web Audio synthesizer + PWA offline support.

## Quick Start

```bash
npm install
npm run dev
```

To play directly on your phone over Wi-Fi, open the **Network URL** printed by `npm run dev` in Safari or Chrome (and optionally tap **Add to Home Screen** for fullscreen standalone PWA mode).
